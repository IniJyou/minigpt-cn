# M5 成对训练示范修订定义 v1

2026-10-19。本轮完成可审阅定义及原创说明示例，未制作正式新增训练/检查集，未加载权重、训练或生成。机器定义为[protocol.json](../configs/m5_lora_revision_v1/protocol.json)，说明示例为[六组成对示例](examples/m5_lora_revision_pairs_v1.json)。下一任务以[current-work.md](current-work.md)为准，Note2Lecture继续暂停。

## 要检验的问题

[30次greedy对照](m5-greedy-results.md)显示，固定step45的完整覆盖仍是14/15，块全字段35/62、macro-F1=0.636535，标题和角色错误仍在。旧train只有36条95块，英文表面形式覆盖有限；这些事实提出“补充边界示范可能有帮助”的假设，尚未证明原因。

本次只检验：在相同基座、初始化、LoRA、优化器、前45步学习率轨迹、解码和评分下，修订训练数据包能否改善结果。对照A复用旧step45及其已完成的greedy valid结果；条件B从同一基座重新初始化adapter，使用旧train加新成对示范，只训练45步。**不接着训练旧adapter，不改变输出接口，不把规则结果覆盖进模型回复。**

新增数据会改变具体样本、顺序、每条曝光次数和监督token数；相同优化步数不代表相同token预算。结论只针对这份数据包在固定步数下的效果，不能分别归因于数量、某一类示范或重复次数。单种子、小样本结果不作统计显著性或泛化保证。

## 样本配额与制作方式

计划新增24对/48条训练示范，另留12对/24条新的开发检查样本。每对是两条完整记录，保留同一数学内容或上下文载荷，只改变约定的边界因素；需要新增论证、活动角色或末尾块的组，逐项记录实际改变，不能声称字节只变一个字符。

| 编号 | 边界问题 | 训练配额 | 新检查配额 | 必须体现的变化 |
| --- | --- | ---: | ---: | --- |
| P1 | 标题提取与类别独立 | 4对/8条 | 2对/4条 | 粗体后冒号与空格正文；ATX/列表前缀。明确哪些字段保持、哪些改变 |
| P2 | 英文角色形式 | 4对/8条 | 2对/4条 | Example/Examples、Theorem/Proposition等已列完整词；角色相同的变体标签也保持相同 |
| P3 | 活动标记与正文提及 | 4对/8条 | 2对/4条 | 实际引入结构，对比正文引用、围栏代码或引用块；不能见关键词就改类 |
| P4 | 证明请求与证明正文 | 4对/8条 | 2对/4条 | 相同待证对象，要求证明为other/out_of_scope，已给出论证为proof |
| P5 | uncertain及原因 | 4对/8条 | 2对/4条 | 原生复合标记ambiguous、同块独立角色mixed_roles、指代不足insufficient_context；不得用uncertain掩盖规则缺口 |
| P6 | 多块输入完整覆盖 | 4对/8条 | 2对/4条 | 训练分别4→5、5→6、6→7、7→8块；新增末块，其余原文/编号/目标不变。检查组也必须包含5块和8块端点 |
| 合计 | 6类问题 | 24对/48条 | 12对/24条 | 不按看到的模型结果追加或替换样本 |

P1每侧均含非空与null标题，不把所有粗体都当标题；P2训练和检查各至少一对Example/Examples及一对Theorem/Proposition。P3每侧均覆盖普通正文引用、围栏代码与引用块，同一片段可保留多个独立块。P5训练4对覆盖ambiguous↔明确单类、mixed_roles↔单角色、insufficient_context↔明确proof，以及ambiguous↔mixed_roles；检查2对固定为后两种原因对照：ambiguous↔mixed_roles、insufficient_context↔明确proof。

两侧都须覆盖八类、三种uncertain原因、非空/null标题与5–8块输入。块数、类数和监督tokens须在实际材料完成后统计；本轮不填造尚不存在的统计。如果配额无法在现行规范下得到明确标签，停止并报告具体冲突，不补新规则或替换成容易得分的材料。

本次新增材料采用助手原创合成文本；不扫描电子书/笔记库、不调用模型编写、不复制或改名复用旧valid/test正文。旧36条train逐条保留，仅在新目录合并为84条。所有新标签由助手按冻结规范复核，明确不是独立人工金标，也不冒称来自真实PDF。

说明附件中的12条均为spec_demo，**排除于新增train、新检查集及后续提示**。它们用于审阅设计，不占48+24配额，也不作为训练证据。本轮只对说明附件做格式、标题和token预算检查。

## 分组与标注契约

沿用[m5-structure-v1.2](m5-task-spec-v1.2.md)、原schema、完整提示、八类、reason枚举、列表边界和标题公式。一条仍是1–8个完整块，单块最多2000字符、片段总计最多6000字符；不拆公式、代码或单个顶层列表项凑样本。只发送input，只监督target/EOS；sample_id、来源、pair_id和review元数据不进模型输入。

制作正文前先分配36个内容家族：训练24个、新检查12个。一个pair及其改写、翻译、换符号/数字、增删块等派生记录属于同一家族，不能跨集合。共同的任务前缀、标签及JSON骨架不是独立来源；必须改变检查侧的具体内容/论证载荷，不能仅给训练模板换变量名。P6追加的末块也继承该内容家族，不跨集合重复使用。

新增train使用split=train，新检查在现有schema中使用split=valid，并在外置manifest中声明role=new_boundary_diagnostic，与原valid分别存放和报告；不创建新test。两者都用source.synthetic=true、独立source_id/group_id。外置pairs.jsonl记录pair_id、phenomenon、group_id、两个sample_id、预期字段变化/不变项、标注依据和差异说明。

在读取任何新模型回复前封存全部72条、家族划分、逐块复核、字符/去空白重复及固定32-gram候选检查。比对新材料内部、旧train和已公开/已查看的开发材料；固定阈值用交集占较短序列32-gram集合的比例≥0.8，短于32字符则补人工逐对检查。只移除通用JSON外壳后比较正文，不忽略任务中的Markdown标记；重复候选需说明，未解决的跨集合派生关系阻塞执行。旧test仅核对已有摘要，不解析正文或标签；它继续封存，也不因这项检查宣称已排除所有语义重复。

新检查样本的正文与目标不参与训练、采样权重、提示编写、检查点选择或运行后替换。设计者会看到其标签，设计方向也来自已看过的valid错误，因此称“训练未使用的开发检查集”，不称盲测或独立金标。

## 评分、判据与停止

沿用原严格evaluate：所有失败进入分母，格式或覆盖失败整条不得取得部分TP。新检查的基座/A/B及原valid的B分别报告原九项门槛；A/B在新检查上的基座增益都使用该检查集的新基座，B在原valid使用已封存同提示greedy基座。旧采样只作为历史参考，不用于本次主比较。

预先区分三种结论：

1. 定向改善：新检查中B相对A的八类macro-F1和块全字段率均严格增加，且原valid的JSON/schema/覆盖、块全字段、整条匹配、macro-F1、非空标题与reason八个指标均不低于A。还须分别报告新检查两成员均正确的完整pair数，按P1–P6分层，不能只挑增加的类别。
2. 质量通过：必须另行满足原九项绝对门槛。即JSON/schema/覆盖100%、块全字段≥0.8、整条≥0.5、macro-F1≥0.75及较同集基座增益≥0.15、非空标题/reason各≥0.8；原valid与新检查分别判定，不合并分母掩盖失败。只满足第1项不能称为质量通过。
3. 混合或未改善：不同时满足定向改善条件，或数据/执行未完整，即如实报告各项变化；不自动扩样、再训、换检查点或增加调用。

即使两侧质量门槛全部通过，本实验仍是开发诊断，不自动启用test或部署。原test/selection及历史检查点保留。OOM、非有限值、初始化/依赖/摘要/家族/输入预算不符、预检失败或输出目录已存在即停并保留现场；普通逐条生成异常计空回复，其他有效配置完整性错误全局停止，所有attempt计入87且不重试。
