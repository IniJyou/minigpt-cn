尤其不能把lr_decay_steps也改成14208，否则既改变原调度，又违反当前恢复契约。
追加处理量为2000×16×512=16384000 tokens；累计116391936 tokens，约2.415372倍原train位置算术曝光，不是实际epoch或新增唯一语料。
原末段valid仍从10000步4.001143降至12208步3.962903，是尝试有限追加的依据；不是保证重复或连贯性会改善。
