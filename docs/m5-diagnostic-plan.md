# M5 有界诊断实验与独立评测边界 v1

日期：2026-10-18。交付是可执行的诊断定义、配对合成材料、六份固定协议及离线token预检；**本轮不运行模型生成或训练**。当前下一任务以[current-work.md](current-work.md)为准。
前项[首次基座结果](m5-qwen-results.md)为JSON16/16、schema14/16、覆盖1/16、严格类别0/54；16条均只返回b0001，14条为与格式例相同的单项body。当前证据只定位到失败现象，尚未证明示例锚定、提示长度或模型容量中的某一项是根因。

## 问题与对照

保持Qwen权重/revision、环境、tokenizer/模板、非思考、种子42、采样0.7/0.8/20、4096输入与1024新增预算、严格评分及失败保留方式不变。复用已冻结运行器，不改旧提示、54块校准、权重或已有结果。

提示条件有三种，其余规范字句不改：

| 条件 | 相对原提示的唯一编辑 | 可检验内容 |
| --- | --- | --- |
| A original | 使用原完整提示 | 在这批新合成材料上的参照 |
| B definition_example | 仅将格式例中的kind值body替换为definition；title/reason仍为null | 输出是否随格式例标签发生同向变化；预检比较A/B token长度 |
| C no_example | 将含单项具体JSON格式例的整行替换成“只输出一个JSON对象。” | 具体单项格式例有无对应的输出变化；删行也改变长度，不能独立归因于锚定或长度 |

B仍是合法annotation格式例，并非给任何输入的答案；明确的“只是格式例，不是固定答案”文字保留。A/B对照不新增“输出几块”的提示，避免同时改变覆盖指令。C下一行仍保留顶层annotations、字段和类型关系的完整要求；不删角色、列表、证明请求、标题、reason或保真规范。

另一个因素是输入方式：

- multi：4组输入，每组3块，块内内容及顺序固定，共4次调用/12块。
- single：同12块逐块独立输入，每次1块，按既有接口把block_id映射为b0001，共12次调用/12块。原组/原编号只写来源映射，不进入模型输入。

两个方式覆盖相同12份原文、标签、标题和reason，不拼补或修复多块回复。单块条件含编号重映射和请求数变化，不能说是只改变了数组长度。材料刻意选择本块自足的内容；实际笔记可能依赖片段上下文，因此本实验不授权把真实笔记任务永久改成单块调用。

## 固定材料和规模

[multi材料](examples/m5_diagnostic_multi_v1.jsonl)、[single材料](examples/m5_diagnostic_single_v1.jsonl)均为本轮合成，不取个人笔记、不复制旧54块。包含普通标题/正文/定义、Thm/Pf/Example、证明请求、同列表项混合角色、代码内指令、练习、独立引用和Lemma。
12块支持数固定为body3、heading1、definition1、theorem2、proof1、example1、other2、uncertain1；6个非空标题、3个非空reason。uncertain只覆盖mixed_roles，不能称全面覆盖。

配对映射与条件清单在[study.json](../configs/m5_diagnostic_v1/study.json)。六个条件为A/B/C各自multi/single：总计**48次生成调用、每个语义块在6个条件下出现、72个块标注位置**。每次调用最多1024新增tokens，预算上界49152新增tokens；无追加种子、参数搜索、失败补抽或跑满分后才停的流程。

在查看本次新模型输出前，固定材料、候选标签、提示、六份协议和本说明的摘要。离线预检只检查schema/配对/标题来源、协议完整性与真实tokenizer长度，不调用model.generate。旧54块不加入这次参数选择，更不转成盲测。

## 运行方法（后续任务执行）

每份协议继承已有运行器接口，protocol_version保持m5-qwen-calibration-v1.1；study_id和diagnostic_condition区分本研究条件。此处CLI的calibration模式读取各自合成材料，不表示正式valid/test。
在WSL中逐一执行六条，每个目录必须不存在；这里不会再次安装或下载：

```bash
for condition in a_multi a_single b_multi b_single c_multi c_single; do
  bash /mnt/d/aiworkspace/transformer/scripts/m5_qwen_wsl.sh \
    --protocol "/mnt/d/aiworkspace/transformer/configs/m5_diagnostic_v1/${condition}.json" \
    --mode calibration \
    --output-dir "/mnt/d/aiworkspace/transformer/logs/m5_diagnostic_v1_${condition}" || break
done
```

基础设施或完整性失败停止，不替换模型、环境或协议；保留已产生响应和failure.json，未完成条件标记未完成，不拿不齐的条件选优。运行器对单条生成异常只尝试一次，以空响应计分并继续当前条件，异常次数必须单列，不增加补抽。
不得在六个条件之间查看质量后改后续提示、标签、预算或样本；全部按已冻结文件执行并统一报告。每次仍输出完整响应/token、输入token、errors、metrics、report、run_manifest。

## 预先规定的分析

主结果逐条件报告严格JSON/schema/覆盖、类别与全部字段的12块分数、固定八类macro/micro-F1、非空标题/reason，以及异常/触及预算。失败回复保留全部分母，不以有效子集替代主分数。

1. **输入方式比较**：multi的回复分母为4，single为12，不直接把两个覆盖百分比当同分母改善。主要比较相同12块的严格类别/全部字段结果；再按原4组汇总“组内所有调用均schema/覆盖有效”和“整组全部字段正确”，得到共同4组分母。single的组汇总只是汇总指标，不生成修复后的multi回复。
2. **示例标签敏感性**：比较A/B相同输入方式与配对单元的变化；另报输出项数量、body/definition预测项数及与各自单项格式例完全一致的回复数。这些是响应行为诊断，坏回复的可辨认项仍不给主指标部分TP。即使出现同向变化，也只支持对格式例敏感，不能证明某个内部机制或总体能力结论。
3. **无例条件**：比较C与A/B的同组指标，并报告长度变化。它同时删除了具体示例和一部分token；不能称作只测长度。该设计没有独立的提示长度/容量消融，不能凭此定位所有根因。
4. **停止和判读**：六个条件完成即停止，无论高低分。若逐块方式仍无法正确处理简单显式角色，先排查基础规范执行；若主要改善覆盖而类别/标题仍错，保留两类问题。观察到某个条件更好只产生后续候选，不在本次宣布任务已解决、LoRA有效或开始训练。

样本很少，每类仅1至3块、每条件单种子，不做显著性或跨来源泛化推断。结果不用于选择checkpoint、回改本批候选，亦不自动追加相同材料上的提示轮次。

## 独立评测边界

当前54块属于规范校准池，本轮12块属于助手制定的诊断池；两者均已被开发过程查看，不能后改成独立test，也没有独立人工金标。不会把multi/single副本跨train/valid/test放置，或把复制/修订/来源近亲当未见来源。
真正训练/最终评测前，需另项确定来源文档及复制/派生家族归属、在切块前按家族划分；固定快照、SHA、划分与标注审阅后再开发训练材料。正式test不得参与本次六条件选优或训练调参；如果查看test错误再改系统，必须如实记为已使用并另设最终评测边界。
已有笔记授权只支持后续按需有界取样，本轮没有取新文档、全库扫描、上传笔记或生成正式SFT。LoRA的数据划分、配置与验收门槛仍待后续定义，不由本诊断协议推定授权。
