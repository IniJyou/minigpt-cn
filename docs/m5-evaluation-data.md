## 家族核对的关键发现

检查仅限清单内11份快照及其原件摘要，计算全部55对精确/去空白全文、32字符片段Jaccard与包含率，再核对章节、实际例题和共享段落。没有递归扫描笔记库，不宣称全库没有派生关系。

1. 两份预留版本的32-gram Jaccard为0.898374，较短版本片段包含率约97.69%，章节和长段落相同；合并为一个test家族，只从其中一个版本取样，另一版本同步排除出其他集合。
2. 一份拟test材料与旧训练来源具有相同年份、原始数据、拟合参数和预测结果的完整例题。全文Jaccard仅0.013681，仍按共享例题归并作泄漏控制，整份预留材料隔离，不增加训练记录或计作独立test。
3. 两份旧来源之间存在长篇相同推导与例题，归并关系另行记录；它们原本均在训练排除桶，未造成新跨集合分配。
4. 另外两份预留来源在此11份范围内未发现实质共享段落或派生链接，分别保留为valid家族。通用公式、矩阵符号或Markdown表格分隔线的相同，不单独证明复制。

这些是限定范围内的来源家族结论，复制方向和范围外历史仍未知。未将“相似度低”当作独立性的充分证明。旧真实排除桶继续保留，不能声称其中6份文档都属于同一真实家族。

片段按v1.1取完整顶层块；列表每个顶层项一块，嵌套内容跟随父项。未以并段方式制造mixed_roles，没有拆公式/代码/引用，不把前块角色传播到后块。所有候选与原训练95块之间，以及valid/test之间，精确、去空白相等及双侧长度>=80的32-gram Jaccard>=0.60候选检查均无跨集合命中；此结果不代替语义家族核对。

## PDF补充来源的实际探测

用户追加授权从本地电子书目录取样。本轮仅列指定目录的直接子项，选择3份明确PDF，逐份检查PDF页1、5、20及文件元数据/SHA；不是全目录或全书提取。三份文件分别431、322、429页，抽查9页文字提取的非空白字符数均为0；渲染并查看了各第20个PDF页，确认样页为扫描图像，包含可供后续转录的显式结构。

现有Poppler已能渲染，无需安装包即可完成本轮只读探测。未运行OCR、下载工具、调用外部服务或上传原书。书名、私人路径、页码、PDF摘要、工具退出信息、空提取文本及三张原页PNG均留在Git忽略的`logs/m5_eval_dataset_20261018_v1/pdf_probe`。

PDF目前只作预留来源，**未直接加入本版Markdown评测候选**。后续少页转录须先记录书名/作者/版本/原PDF页码、检查与已查看来源的例题派生关系，并保留图像对照；定义、定理、证明的段落边界须以版面为依据，不能为了凑uncertain而合并独立段落。公式的上下标、分式、正负号、量词和矩阵逐项校对，转换文本另存为可追溯的规范文本，不冒称与PDF原始字节等价。明显错漏或无法辨识的块先隔离，不能把OCR噪声混入目标。

## 冻结与下一验收点

[候选协议](../configs/m5_eval_candidate_v1.json)绑定父SFT协议、同版提示/schema、家族清单、候选数据、定位/复核及PDF探测摘要。仍继承原八类覆盖、每集合至少2家族/8片段/24块和全部质量门槛，不降低门槛或把已有诊断/合成例改称未见test。

本轮对候选原文定位、输入/目标编号、title/reason、跨集合重复候选和本地tokenizer长度进行检查；真实tokenizer只做模板/长度检查，不加载权重。运行/验收/冻结摘要与脚本在`logs/m5_eval_dataset_20261018_v1`。未改模型/评分源码或重跑pytest，历史测试结果不冒称本轮运行。

当前训练数据就绪为false，原因明确为valid缺4类、test缺uncertain及第2家族；来源核对和候选格式通过不等于覆盖门槛通过。唯一下一任务：**从已授权电子书做少量页面转录与公式/边界对照，核对书籍来源家族后补齐评测缺口，另冻新版数据包**。先试少页，不扩展为全库OCR；不直接开始LoRA训练，Note2Lecture继续暂停。
